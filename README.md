O projeto se refere a um sistema de cadastro de usuário simples, com criptografia de senha e armazenamento de cookies e sistema de logout. Com armazenamento das credenciais em arquivo JSON criptografado.

Para rodar o projeto, necessário instalar o Laragon e executá-lo, Após o Laragon estar rodando colocar a pasta RegistroUsuarios dentro da pasta "WWW".
Localizada no diretório padrão da instalação em: C:\laragon\www

Pode usar a versão 6.0 do Laragon que é gratuita.
